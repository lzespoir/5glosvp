# 0. 核心目标 / Primary Goal

今天只完成一件事情：

> **证明 Sionna RT 可以作为本项目的高保真仿真后端，并将 Sionna 的输出转换成平台自己的统一数据格式。**

English:

> Prove that Sionna RT can serve as a high-fidelity simulation backend and convert Sionna outputs into a platform-owned canonical result format.

最终必须形成如下最小闭环：

```text
Scenario Config
场景配置
     ↓
SionnaBackend
Sionna 仿真适配器
     ↓
Sionna RT
射线追踪
     ↓
Radio Map
无线电地图
     ↓
Canonical Result
平台统一结果
     ↓
JSON + NPZ + PNG
```

本阶段不是开发完整 5G 仿真器。

本阶段不是开发 Web 平台。

本阶段不是完成最终验收指标。

本阶段的唯一目的：

```text
Configuration
    ↓

    ↓

    ↓
Artifact
```

跑通。

# 1. 开发原则 / Development Principles

必须遵守以下原则。

## 1.1 优先使用官方 API

不得自行重新实现：

* Ray Tracing / 射线追踪
* Radio Propagation / 无线传播
* Antenna Pattern / 天线方向图
* Path Computation / 传播路径计算
* Radio Map / 无线电地图

这些能力优先直接使用 Sionna RT。

---

## 1.2 不生成伪造 KPI

本阶段禁止人为构造：

```text
RSRP = -80 dBm
SINR = 20 dB
Throughput = 100 Mbps
```

作为“仿真结果”。

所有标记为 Sionna Simulation Result 的结果必须真正来源于 Sionna RT。

如果某项指标当前无法由 Sionna RT 得到：

```json
{
  "status": "not_available",
  "reason": "not implemented in Day 1"
}
```

不得伪造数值。

---

## 1.3 平台不能直接依赖 Sionna 数据结构

业务层禁止直接到处使用 Sionna Object。

必须经过：

```text
Sionna
   ↓
SionnaBackend
   ↓
Canonical Result Model
平台统一结果模型
```

未来才能接入：

```text
FastBackend
SionnaBackend
ExternalBackend
HuaweiBackend
OtherBackend
```

而不修改上层业务。

# 6. 第一核心接口：SimulationBackend

文件：

```text
src/simulation/base.py
```

定义统一仿真后端接口。

推荐：

```python
from abc import ABC, abstractmethod
from pathlib import Path

from .models import (
    ScenarioConfig,
    SimulationResult,
)


class SimulationBackend(ABC):
    """
    仿真后端统一接口
    Unified simulation backend interface.
    """

    @property
    @abstractmethod
    def name(self) -> str:
        """后端名称 / Backend name."""
        raise NotImplementedError

    @abstractmethod
    def health_check(self) -> dict:
        """
        环境检查
        Check whether the backend is available.
        """
        raise NotImplementedError

    @abstractmethod
    def load_scenario(
        self,
        config: ScenarioConfig,
    ) -> None:
        """
        加载场景
        Load simulation scenario.
        """
        raise NotImplementedError

    @abstractmethod
    def run(self) -> SimulationResult:
        """
        执行仿真
        Run simulation.
        """
        raise NotImplementedError

    @abstractmethod
    def export(
        self,
        result: SimulationResult,
        output_dir: Path,
    ) -> None:
        """
        导出实验产物
        Export simulation artifacts.
        """
        raise NotImplementedError
```

具体类型允许根据当前 Python/Pydantic 版本合理调整。

但接口语义不要改变。

```text

     ↓
```
