# 2. 修复 Runtime 语义

当前 Code Review 发现：

`total_runtime_seconds` 在 Artifact Export 之前停止计时。

必须修正。

以后统一存在：

```text
simulation_runtime_seconds
仿真计算耗时

artifact_export_runtime_seconds
Artifact 导出耗时

total_runtime_seconds
完整实验耗时
```

未来预留：

```text
optimization_runtime_seconds
优化算法耗时
```

但 Day 1.1 不需要实现优化器。

---

# 3. Runtime 定义

## simulation_runtime_seconds

只测：

```text
backend.run()
```

内部真正仿真计算部分。

---

## artifact_export_runtime_seconds

测：

```text
backend.export(...)
```

---

## total_runtime_seconds

定义：

```text
Experiment Start
      ↓
Scenario Load
      ↓
Simulation
      ↓
Result Conversion
      ↓
Artifact Export
      ↓
Experiment Finish
```

即：

```text
total_runtime_seconds
≈
scenario_load
+
simulation
+
result_conversion
+
artifact_export
+
orchestration_overhead
```

不要人为要求：

```text
total =
simulation + export
```

因为存在其他 overhead。

测试只需要保证：

```text
total_runtime_seconds
>= simulation_runtime_seconds
```

以及：

```text
total_runtime_seconds
>= artifact_export_runtime_seconds
```

# 16. Store Interface

不要直接把 File Store 写死。

定义：

```python
class ExperimentStore(ABC):

    def create(
        self,
        experiment: ExperimentRecord
    ) -> ExperimentRecord:
        ...

    def get(
        self,
        experiment_id: str
    ) -> ExperimentRecord | None:
        ...

    def update(
        self,
        experiment: ExperimentRecord
    ) -> ExperimentRecord:
        ...

    def list(
        self,
        limit: int = 50,
        offset: int = 0
    ) -> list[ExperimentRecord]:
        ...
```

然后：

```python
class FileExperimentStore(ExperimentStore):
```

以后：

```text
PostgresExperimentStore
```

可以替换。

# 26. POST /api/v1/experiments

这是 Day 2 最重要的 API。

请求：

```json

  "name": "第一次 Sionna API 实验",
  "scenario_id": "SIONNA-DEMO-001"
}
```

服务端：

```text

2. Generate Experiment ID

3. Create ExperimentRecord

4. status = CREATED

5. Persist

6. Run Experiment

7. Update RUNNING

8. Run Backend

9. Save Result

10. status = SUCCEEDED

11. Return Experiment
```
